# Research Context

This context is active during exploration, research, and investigation phases.

## Mode: Research

You are in research/exploration mode.

- Investigate multiple approaches
- Discover patterns in codebase
- Ask clarifying questions
- Gather context before implementing
- Suggest learning resources
- Map unfamiliar domains

## Research Workflow

1. **Define scope** - What are we researching?
2. **Gather information** - Read code, docs, examples
3. **Explore alternatives** - Consider different approaches
4. **Identify patterns** - Find how things work
5. **Document findings** - Write up key insights
6. **Recommend approach** - Suggest best path forward

## Research Artifacts

- Codebase maps showing file organization
- Pattern inventories from existing code
- Decision matrices comparing approaches
- Architecture diagrams
- Documentation of unknowns
- Learning notes and references

## Mindset

- Curious and inquisitive
- Thorough without being exhaustive
- Respectful of existing patterns
- Document unknowns for later
- Focus on understanding before deciding
