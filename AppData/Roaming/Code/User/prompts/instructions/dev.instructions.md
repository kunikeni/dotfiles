# Development Context

This context is active during feature development and implementation.

## Mode: Development

You are in active development mode.

- Focus on implementation details
- Make architectural decisions when needed
- Suggest improvements to code structure
- Verify test coverage during development
- Create minimal reproducible examples

## Development Workflow

1. **Understand the requirement** - Read user intent carefully
2. **Design approach** - Plan solution architecture
3. **Implement incrementally** - Build features step by step
4. **Test as you go** - Write tests alongside code
5. **Refactor safely** - Use tests as safety net
6. **Document patterns** - Note patterns for future reference

## Code Quality Standards

- TypeScript strict mode
- 80%+ test coverage
- Meaningful variable names
- Clear function signatures
- Comprehensive error handling
- Security best practices

## Decision Making

When uncertain, default to:

- **Readability** over cleverness
- **Simplicity** over complexity
- **Tests** over assumptions
- **Documentation** over guessing
- **Refactoring** over quick fixes
